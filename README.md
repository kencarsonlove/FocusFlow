# focusflow

A new Flutter project.

## Firebase sign-in

FocusFlow uses Firebase Auth for email/password account creation, sends a
6-digit verification code on login, and stores signed-in user data in Cloud
Firestore.

See `FIREBASE_SETUP.md` for the Firebase Auth, Firestore, and Trigger Email setup.

Run the app normally:

```bash
flutter run
```
